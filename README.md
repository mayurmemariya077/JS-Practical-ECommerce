# 🛍️ Amazon India — Premium Shopping Website

✨ A modern and interactive shopping website inspired by Amazon, built using HTML, CSS, Bootstrap, and JavaScript.

## 🌟 About The Project

Amazon India is a responsive shopping website where users can explore products, add items to their cart, manage quantities, and calculate the total price. Users can also add new products, update existing products, and delete products through an interactive interface.

The project features a premium UI with elegant colors, smooth hover animations, stylish product cards, and interactive Bootstrap modals.

## 🚀 Features

- 🛒 **Shopping Cart** — Add products to the cart.
- ➕ **Increase Quantity** — Increase the quantity of cart items.
- ➖ **Decrease Quantity** — Decrease product quantities.
- ❌ **Remove Products** — Remove items from the cart.
- 💰 **Total Price Calculation** — Automatically calculate the cart total.
- 💳 **Checkout Option** — Interactive checkout functionality.
- ➕ **Add New Products** — Add products through a form.
- ✏️ **Update Products** — Edit existing product details.
- 🗑️ **Delete Products** — Remove products from the product list.
- 🔍 **Product Search** — Search products through the navigation bar.
- 💾 **Local Storage** — Keep cart data saved in the browser.
- 📱 **Responsive Design** — Adapt the interface to different screen sizes.
- 🎨 **Premium UI** — Modern background, elegant navbar, and stylish buttons.
- ✨ **Hover Animations** — Smooth product card lift, image zoom, and button effects.
- 🪟 **Bootstrap Modals** — Interactive cart, add-product, and update-product windows.

## 🧰 Technologies Used

- 🌐 HTML5
- 🎨 CSS3
- ⚡ JavaScript
- 🅱️ Bootstrap 5.3.8
- 💾 Browser Local Storage

1. 📥 Download or clone the project.
2. 📁 Open the project folder in your code editor.
3. 🌐 Open `index.html` in your browser.
4. 🛍️ Explore products and try the shopping cart features.

The main objective of this project is to practice frontend web development by building an interactive shopping website using JavaScript DOM manipulation, event handling, arrays and objects, browser Local Storage, and Bootstrap components.
